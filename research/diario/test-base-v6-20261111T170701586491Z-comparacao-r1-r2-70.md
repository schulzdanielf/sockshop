## Integridade e comparabilidade

- Os 70 run IDs são únicos (sem sobreposição r1/r2); as duas coortes cobrem as mesmas 35 combinações de serviço×falha, usadas como chave de pareamento.
- Corpus congelado, hash, retriever v6, modelo Qwen 3.5, temperatura 0,1 e seed 20261107 são iguais entre avaliações.
- Cada bloco teve precollection MCP própria: r1 315/315 `ok`; r2 315/315 `ok`, sem `no_data` ou erro de backend. A coleta r2 consultou Prometheus, Loki e Tempo em baseline/fault/post para cada run.
- Diagnósticos r2: 35 casos completos, 70 respostas Skill/RAG, zero erros finais. Um erro de JSON na primeira tentativa RAG de `carts-network-latency-r2` foi recuperado por `retry-1`; a tentativa inválida foi preservada.
- **Diferença de seleção:** sete CPU-hog r2 só entraram após a emenda retrospectiva v2: média aritmética na janela fault ≥ 0,80 da quota e sem requisito de duração sustentada; o valor sustentado original de 95% ficou como diagnóstico. Isso altera apenas a elegibilidade do bloco r2; os artefatos v1 permanecem `partial`, não houve reinjeção e nenhum run r2 entra no treino. Consulte a [emenda](../../experiment/eval/memory_hog/out/test_replication/test-replication-20261110-post-reboot-2312/cpu_mean80_amendment_v2.json) e o [relatório de campanha v2](../../experiment/eval/memory_hog/out/test_replication/test-replication-20261110-post-reboot-2312/collection_report_v2.json).
- O conjunto de 70 é uma agregação descritiva de dois blocos temporais, não 70 observações IID nem uma avaliação cega. A seleção CPU distinta deve ser considerada ao interpretar mudanças entre blocos.

## Leitura dos resultados

- Skill teve pequena diferença pontual de acurácia conjunta, de 11/35 para 12/35 (+2.9 pp), mas 11/35 pares mudaram de estado de acerto.
- RAG caiu de 18/35 para 14/35 (-11.4 pp); 10/35 pares mudaram, com 7 acertos apenas em r1 e 3 apenas em r2. O IC bootstrap pareado inclui zero.
- O agregado RAG é 32/70 (45,7%), mas não deve ser interpretado como uma única coorte homogênea: além do bloco temporal, a regra retrospectiva ampliou a elegibilidade dos sete CPU r2.
- Para uma estimativa confirmatória de variabilidade, a próxima replicação deveria manter o mesmo gate de intensidade para todos os blocos e ser avaliada às cegas, sem alterar corpus, prompts, retriever ou parâmetros.
