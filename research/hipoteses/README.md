## Template para novas hipóteses

Copie a estrutura de uma hipótese existente. Seções obrigatórias:

1. **Status / datas / links** — rastreabilidade
2. **Motivação** — evidência (do diário ou de resultados anteriores) que justifica a hipótese
3. **Hipótese formal** — uma frase, falsificável, com condição explícita de sucesso
4. **Métricas** — como medir
5. **Critérios de validação e refutação** — definidos *antes* do experimento
6. **Riscos / questões abertas**
7. **Registro de resultados** — preenchido ao longo do tempo, com links para entradas do diário
